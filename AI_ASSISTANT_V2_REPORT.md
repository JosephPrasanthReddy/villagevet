# VillageVet AI Assistant V2 — 25 Aug 2026

## What changed

- Added real streamed Gemini responses through `/api/chat/stream` using Gemini `streamGenerateContent`.
- The assistant now begins showing the response as Gemini generates it instead of waiting for the full answer.
- Added a three-dot thinking state before the first response chunk and a subtle streaming cursor while text is arriving.
- Added automatic scroll-to-latest during streaming and conversation updates.
- Added context-aware follow-up question chips generated by Gemini after each answer. The hidden suggestion block is parsed by the client and never shown inside the answer text.
- Added farmer-friendly answer guidance for animal-health/productivity questions: concise summary, likely factors, things to check, urgent warning signs, and useful clarifying questions when relevant.
- Kept veterinary safety boundaries: no diagnosis, prescription, medicine dosage, injection schedule, or treatment changes.
- The selected VillageVet website language is now sent to the backend and explicitly controls the response language.
- Localized the chatbot welcome, starter prompts, thinking state, placeholder, voice messages, disclaimer, error copy, and follow-up labels for English, Telugu, Hindi, Tamil, Kannada, and Malayalam.
- Added a visible "Replies in <language>" status chip in the AI header.
- Added auto-growing message input and a slightly wider desktop chat panel for readability.
- Preserved voice input, reset, Markdown rendering, rate limiting, `.env` secret handling, and the working Gemini connection.
- `/api/health` now also returns `"streaming": true`.

## Run

From `chatbot-polish`:

```powershell
npm.cmd install
npm.cmd run dev
```

Keep the existing `.env` with `GEMINI_API_KEY`, `GEMINI_MODEL`, and `AI_PORT`.

## Health check

Open:

`http://localhost:5173/api/health`

Expected key fields:

```json
{
  "ok": true,
  "aiConfigured": true,
  "streaming": true
}
```
