# VillageVet visual + language update

## Included languages
- English
- Telugu
- Hindi
- Tamil
- Kannada
- Malayalam

The language selection is persistent using localStorage. The site uses one shared language context and a translation layer for existing hard-coded UI strings, while the main navigation and homepage content use structured translations.

## Visual update
The homepage hero has been redesigned with a stronger agricultural/editorial layout, richer depth, layered cards, farmer-first stats, organic shapes, and a VillageVet ecosystem strip. Service cards receive stronger visual depth and organic hover treatment. The language selector is available in the desktop/mobile navigation and footer.

## Run locally
After extracting the project:

```powershell
npm install
npm run dev
```

For production verification:

```powershell
npm run build
```
